# OMEGA 0.10 — H009 Game-Script Elasticity

H009 was pre-registered in OMEGA 0.1: score state changes offensive play mix and defensive personnel, so player tackle expectation may be nonlinear in projected game script.

OMEGA 0.10 deliberately avoids sportsbook spread/total information. Each tackle-opportunity play is assigned to an offense-perspective pre-play state: trailing by 7+, neutral within 6 points, or leading by 7+. For a target game, state shares are forecast from strictly prior offense-generated and defense-allowed opportunity-state histories. Family shares within each state are forecast the same way. The resulting script-conditioned family share is mixed with frozen H008 family shares by a single beta chosen on 2021–2023; beta=0 exactly reproduces H008.

2024 is diagnostic-directed confirmation, not a pristine holdout. 2025 remains sealed. If H009 does not robustly beat H008, the script mechanism is rejected without post-hoc state/position rescue.
